# Material & Inventory Project Manager

A standalone Vite-based material and inventory management application for creating projects, tracking materials and quantities, managing item photos and notes, generating PDF reports, and saving/restoring project backups.

The application works offline and stores project data locally on the user's device using LocalStorage.

## Features

- Create, edit, duplicate, and delete projects
- Track materials and inventory quantities
- Support for Piece, Meter, Kg, Liter, Box, Roll, Pack, and custom units
- Add item photos and notes
- Search, filter, and manage inventory items
- Increase/decrease quantities easily
- Project status management
- Light and dark mode
- PDF report generation
- Save complete project backups
- Restore projects from saved backups
- Restore projects from PDFs generated by this application
- LocalStorage-based data persistence
- Responsive desktop and mobile interface
- Progressive Web App (PWA)
- Offline support

Backup and Restore

The application provides a user-friendly backup and restore system.

Save Backup stores the complete project information, including inventory data and photos.

Restore Project can restore backups created by the application.

PDF reports generated by the application can also be restored. External PDF files are not accepted as project backups.

PWA and Offline Use

The application supports an installable Progressive Web App (PWA).

After building the application with:

npm run build

the generated dist folder can be served using a static server or previewed with:

npm run preview

Once installed, the application can work offline and project data remains stored locally on the device through LocalStorage.
